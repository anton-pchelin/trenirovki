# Тренировки — веб-приложение для айфона

Запись тренировок (кроссфит, ТА): подходы, комплексы WOD с таймерами, история, рекорды, 1ПМ, блины, Excel.
Пользователь — не программист, общаться по-русски простыми словами. Задания и интервью — в `задания/тренировки_айфон/` (в git не попадает).

- Адрес: https://anton-pchelin.github.io/trenirovki/ (GitHub Pages из ветки `main`, корень). Хранилище `anton-pchelin/trenirovki` — открытое.
- Установка: Safari → «Поделиться» → «На экран Домой». Работает без интернета.
- Без сборки и сторонних библиотек: обычные страницы и модули JS. Excel пишется своим кодом (`js/xlsx.js`).

## Карта файлов
- `index.html` — страница; `APP_BUILD` — версия (менять при каждой выкладке!).
- `sw.js` — офлайн-кэш; список `ASSETS` должен содержать каждый файл (проверяет `tests/sw.test.js`).
- `js/app.js` — запуск, общий тик 4 раза/с. `js/router.js` — стопка экранов.
- `js/screens.js` — календарь, упражнения, настройки, тренировка. `js/item.js` — экран упражнения и комплекса (таймер). `js/history.js` — история/график/рекорды. `js/picker.js` — выбор и «своё».
- `js/store.js` — хранение (одна запись в IndexedDB). `js/queries.js` — выборки по истории. `js/workout.js` — действия с тренировкой.
- `js/calc.js` — чистые расчёты (разбор чисел/времени, рекорды, 1ПМ, проценты, блины). `js/clock.js` — таймер комплекса.
- `js/data-exercises.js` (~200 упр.), `js/data-wods.js` (~55 комплексов). id = категория+номер: **новые — только в конец списка**, иначе сломается история.

## Формат данных (state)
`workouts[]: {id, date 'ГГГГ-ММ-ДД', created, finished, items[]}`;
упражнение `{kind:'ex', exId, fields:['w','r','d','t'], sets:[{w,r,d,t,done}], note}` (t — секунды);
комплекс `{kind:'wod', wodId, def (копия описания), res:{time|rounds,reps|total,intervals|done,capped}, weight, rx, timer:{start,stopped}}`.
Также `customExercises, customWods, favorites, recent, settings, oneRM{exId:кг}, lastBackup, activeId, rest`.
Менять формат — только дополняя, старые записи пользователя должны читаться.

## Правила (решения пользователя)
- В историю/рекорды/Excel идут только подходы с ✓. 🏆 — строго лучше всего, что было раньше.
- 1ПМ = вес × (1 + повт/30) по подходам ≤10 повт., можно поправить руками; проценты 50–95% с округлением до 2,5 кг.
- Рекорд комплекса — отдельно RX и без RX. Excel — строка на подход, комплекс — строка на результат.
- Таймеры: экран не гаснет (wakeLock), звук + вспышка; вибрации на айфоне у сайтов нет.

## Проверки и выкладка
- `node --test tests/*.test.js` и `python tests/check_xlsx.py tests/out.xlsx` (после тестов).
- Локально: `python -m http.server 8765` (на localhost кэш выключен; `?sw` — включить).
- Выкладка: поднять `APP_BUILD` в `index.html` → commit → `git push` (Pages обновится за 1–2 мин).
